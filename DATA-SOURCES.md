# Data sources and provenance

- **Corporate announcements:** NSE publishes an RSS feed page and announcement feeds. The Vercel endpoint reads the all-announcements feed and retains each item's title, date, description, and link, then matches portfolio company names in the item title to reduce false matches from counterparties mentioned only in descriptions. It can miss filings if the RSS title does not identify the issuer. The UI links to the source filing where the feed provides a direct item URL. See [NSE RSS feeds](https://www.nseindia.com/static/rss-feed) and [NSE corporate filings](https://www.nseindia.com/companies-listing/corporate-filings-announcements).
- **EOD price and volume:** The Vercel endpoint requests daily chart candles for Yahoo Finance `.NS` symbols, uses the latest two closes for daily move, and compares latest volume to the prior 20 sessions. This is an unofficial Yahoo Finance chart endpoint, not an exchange-authorized or guaranteed API. Source display links point to each Yahoo Finance quote page.
- **Annual reports and transcripts:** The app opens the selected company page on Screener as a discovery route to company documents. Screener's Reliance page currently lists recent announcements, annual reports, and concall transcripts linking to BSE/company source files; availability varies by ticker. FINN does not download or analyze the documents in this prototype. For example, [Reliance documents on Screener](https://www.screener.in/company/RELIANCE/) exposes annual reports and transcript links, and those linked company/exchange documents—not Screener's generated commentary—are the primary-source evidence required for pull analysis.
- **Sample fallback:** Initial feed stories and research metrics in the local demo are illustrative. The sample UI remains visible if API routes are unavailable. Never treat it as current data or investment advice.
